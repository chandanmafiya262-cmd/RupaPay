RupaPay phone/PWA package

IMPORTANT:
A browser cannot install a local folder as a full PWA unless the files are served over HTTPS (or localhost). Do not open index.html directly from the Files app and expect Install to appear.

Phone-only setup:
1. Upload these files to an HTTPS static host.
2. Open the HTTPS address in Chrome.
3. Use Chrome menu -> Add to Home screen / Install app.
4. RupaPay opens as a standalone app.

Admin:
The prototype contains the Admin Panel inside the same app. Open the app, choose Admin Panel on the login screen, and use the demo PIN 123456.

This is a prototype. Admin authentication, users, balances, withdrawals and payments are local/demo data and are NOT secure for real money. Production needs a real backend and server-side authorization.
